# Base Converter

一个无限精度浮点数进制转换器侧边栏扩展。


## 功能

- 支持任意进制之间的数字转换（2-36 进制）
- 无限精度浮点数支持
- 实时转换预览
- 简洁直观的界面
- 多进制计算器
- 自定义函数（Python语法）计算
- 中英文切换

## 支持进制

- 二进制 (Base 2)
- 八进制 (Base 8)
- 十进制 (Base 10)
- 十六进制 (Base 16)
- 以及 2-36 之间的任意进制

## 使用方法
### 进制转换器
1. 点击活动栏中的 Base Converter 图标
2. 在输入框中输入数字
3. 选择源进制和目标进制
4. 查看转换结果
![alt text](image.png)
### 多进制计算器
1. 输入正确多进制计算表达式
2. 选择输出进制
3. 点击计算按钮
